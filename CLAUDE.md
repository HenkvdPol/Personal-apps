# Collaborating with Claude

Follow [AGENTS.md](AGENTS.md) for repository conventions and checks.

For implementation, start from the latest `main` on your own branch. Open a focused pull request with the change summary, checks performed, and any remaining device testing. Coordinate with Codex through GitHub issues and pull requests when work overlaps.

For an independent review, inspect the pull request diff and report actionable findings with file and line references. Prioritize regressions, Expo Go compatibility, and gaps in verification. Ask before pushing changes to another contributor's branch. Leave merging to the repository owner unless explicitly authorized.
